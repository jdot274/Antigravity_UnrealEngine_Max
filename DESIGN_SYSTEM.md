# Antigravity Design System

## Overview
This repository utilizes two distinct, separate design systems. Assets and UI elements must adhere strictly to one of these two styles depending on their context.

---

## 1. SYSTEM A: Antigravity Neon (The "Repo" Style)
**Context:** Used for the code repository, developer tools, CLI interfaces, and internal "Antigravity" branding.
**Visuals:** Dark mode, high contrast, cybernetic.

### Characteristics
*   **Color Palette:** Deep blacks, vibrant cyans, electric purples, and neon blues.
*   **Gradients:** Linear and complex mesh gradients.
*   **Imagery:** Abstract, futuristic symbols (e.g., the stylized "A").
*   **Vibe:** Coding, Engineering, Sci-Fi, "Backend".

**Asset Reference:**
*   `tools/gemini-vscode-extension/assets/icon_neon_variant.png`

---

## 2. SYSTEM B: Radial 2d3d (The "App" Style) — **ACTIVE**
**Context:** Used for user-facing applications, app icons (iOS/macOS style), and "Role Playing" elements.
**Style ID:** 25

### Characteristics
*   **Name:** Radial 2d3d
*   **Visual Definition:** A "2d3d" effect using 2D radial gradients to simulate depth without full 3D rendering.
*   **Shape:** **Glass Apple Watch Outline** (Squircle with glossy container).
*   **Gradients:** **Simple Gradients**. Smooth interactions of color. No noise, no complex texture.
*   **Colors:** Vibrant, distinct, high saturation.
*   **Philosophy:** "Role Playing" objects — icons should feel like physical, tactile objects or badges within the interface.
*   **Exclusions:** explicit NOT Standard SDF, NOT PBR Alpha, NOT pure Glassmorphism.

**Current Usage:**
*   **Extension Icon:** The Golf Course icon currently in use (`tools/gemini-vscode-extension/icon.png`).
